# User Flows

## Traveler
Home → Origin/Destination → Search → Destination → Filter/Map → Business/Service Detail → Save/Book/Contact.

Example: Addis Ababa → Wolaita Sodo → Hotels → filter → hotel detail.

## Business
Register → Business Draft → Details → Category → Location → Contact/Hours → Services → Media → Verification Documents → Submit → Admin Review → APPROVED/REJECTED.

## Booking
Service → Select date/party → Check availability → Booking → Payment if needed → Confirmation → Completion → Review.

## Admin
Verification Queue → Submission → Review → Approve/Reject → Audit → Notify business.

## Trip
Create Trip → Origin/Destination → Dates/Budget/Interests → Days → Add/reorder itinerary items → Save.
